Privacy Policy

Last updated: September 1, 2026

Welcome to the privacy policy of WearTemr. This application is a terminal emulator for Wear OS that downloads and executes packages from a server — no local data storage, no intermediary services, and no user information collection.

1. Information We Do Not Collect

WearTemr does not collect, store, or share any personal data. The application has no data persistence functionality — it only serves as a client interface for downloading and running packages from the configured server.

2. No Data Storage

WearTemr does not retain any information on your device between sessions. No terminal history, no configuration data, and no user credentials are stored locally. All operations are ephemeral and session-based only.

3. Server Communication

WearTemr communicates exclusively with the designated package server you configure. Network traffic is limited to package downloads and command execution requests. No data is sent to any third-party services, analytics platforms, or cloud infrastructure.

4. No Analytics or Monitoring

WearTemr does not use any analytics, crash reporting, or monitoring services. Your usage patterns and activities are never tracked or transmitted.

5. Permissions

The app requires internet permission solely for downloading packages from the server. No other device permissions are requested or used.

6. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Changes will be posted on this page.
